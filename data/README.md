# Data

The raw and processed data are **not** stored in this repository because of their size (millions of StockTwits posts) and licensing. This folder documents how to obtain and regenerate them.

## Sources

| File | Where to get it |
|---|---|
| `World-Stock-Prices-Dataset.csv` | Kaggle — [World Stock Prices (Daily Updating)](https://www.kaggle.com/datasets/nelgiriyewithana/world-stock-prices-daily-updating/data) |
| `news_data.csv` | Kaggle — US Capital Markets News Headlines (2020–2024) |
| `stocktwits_data/` | StockTwits post export (2020–2022) |

## Expected folder layout (in the shared Google Drive)

```
Group-04 Data/
├── raw_data/
│   ├── World-Stock-Prices-Dataset.csv
│   ├── news_data.csv
│   └── stocktwits_data/          # per-ticker CSVs
├── processed_data/               # generated by the notebook
│   ├── cleaned_stock_prices.csv
│   ├── cleaned_news_data.csv
│   ├── cleaned_stocktwits_posts.csv     # gzip-compressed
│   └── cleaned_stocktwits_daily.csv
└── model_ready_data/
    └── combined_stocktwits_market_data.csv
```

## Regenerating the processed files

Run `notebooks/Group_04.ipynb` top to bottom. It reads from `raw_data/` and writes all `cleaned_*` and `combined_*` files to `processed_data/` and `model_ready_data/`.

> Note: `cleaned_stocktwits_posts.csv` is written gzip-compressed despite the `.csv` name — read it with `pd.read_csv(path, compression="gzip")`.
